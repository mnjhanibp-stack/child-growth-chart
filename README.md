# 성장 백분위 그래프 웹앱 (로컬 실행)

## 1) 설치
터미널(명령프롬프트)에서 이 폴더로 이동 후:

```bash
pip install -r requirements.txt
```

## 2) 실행
```bash
streamlit run app.py
```

자동으로 브라우저가 열리며, 사이트처럼 입력하고 그래프를 확인할 수 있습니다.

## 데이터 기준
- 엑셀 파일 `엑셀.xlsx`의 시트:
  - `연령별 신장` (L/M/S 사용)
  - `출생시 체중 백분위` (L/M/S 사용)

## 입력 팁
- 생년월일 + 측정일 → 만나이(개월) 자동 계산(엑셀 DATEDIF(...,"m") 방식)
- 그래프 x축 표기: `~년 ~개월`
